Please note that you can find all tests under the “tests” folder in the munchmate repo. You can access both integration and unit tests at this link https://github.com/keyonkaboly/munchmate/tree/main/tests simply by clicking the respective folder: https://github.com/keyonkaboly/munchmate/tree/main/tests/unit and https://github.com/keyonkaboly/munchmate/tree/main/tests/integration.
Testing evidence can be found at https://github.com/keyonkaboly/munchmate/actions. Please note that for pytest-coverage it can be found under the ‘raw logs’ under each GitHub actions test run on each commit. 
GitHub actions was set up with both PyLint and PyTest since the first few days of Feburary. Pytest have been running on every commit. Pytest coverage reports were implemented a bit later around start of March.
